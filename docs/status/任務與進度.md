## 目前功能

| 功能 | 現況 |
| --- | --- |
| 公開作品集 | 中英雙語與語系記憶；首頁五區塊、只顯示精選作品，/projects/ 顯示全部公開作品。 |
| 作品視窗 | 期間與標題同列、角色在下一行；原生上下捲動及背景鎖定；圖片含封面，左滑下一張、右滑上一張，首尾循環；固定比例圖片區，提供箭頭與張數。 |

| 自訂後台 | 五類內容、雙語欄位、草稿／公開／精選、版本衝突保護與排序；不使用 Django 原版 admin。 |
| 圖片管理 | 不需描述；縮圖拖曳或箭頭排序，首張封面、其餘圖集。刪除僅解除作品引用，儲存後生效，保留私人原檔。儲存等待時鎖定拖曳。 |
| 準備更新 | 檢查公開內容、匯出 JSON 與實際引用素材，再建置靜態預覽；失敗保留舊預覽。GitHub Pages 只手動發布。 |
| 備份 | PostgreSQL dump、私人素材與 SHA-256；還原至新的 lotus_restore_* 資料庫，保留現用資料。 |

## 維護邊界

- 所有公開內容從發布快照讀取，訪客不依賴本機資料庫或 API。僅匯出公開且驗證通過的內容與引用素材。
- 草稿可缺翻譯；公開必要文字須中英齊全。角色可兩語皆空，只填一語須補齊；圖片描述不是發布必填項。
- 內容版本與交易鎖避免編輯、排序、匯出及備份靜默覆寫；遷移歷史須保留。
- 作品名稱、日期、角色及成果依使用者資料，不補造。MRI 數字為履歷記載，未在本案重新驗證模型或臨床效果。
- 未提供正式網址時不產生虛構 canonical；完整作品集的 canonical 與 sitemap 保留專案子路徑。
